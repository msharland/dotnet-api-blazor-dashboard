
# .NET API Blazor Dashboard

A lightweight full-stack .NET application demonstrating a Blazor dashboard backed by an ASP.NET Core Web API.

## Features

* Blazor web interface
* ASP.NET Core REST API
* Dependency injection
* API service layer
* Async HTTP communication
* Configuration and logging
* Basic error handling

## Architecture

`Blazor UI → ASP.NET Core API → Service Layer`

## Technology

* C#
* .NET
* Blazor
* ASP.NET Core

## Status

Active development with additional dashboard and API functionality added over time.
